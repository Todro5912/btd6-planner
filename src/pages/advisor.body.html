Strategy Advisor

You know which monkeys you want, but not how to use them. Pick them here. You get each one's crosspath and job, a round-by-round build order, the gaps to fix and tips for the map.

About this advice

End crosspaths come from each tower's best crosspaths on its guide page. They are picked together so your team can hit every bloon property the mode sends (camo, lead, purple, black, white, MOAB-class, DDT, BAD) and so the total fits the cash the mode pays by about 88% of the way through. When cash is short, a cheaper tier of the same path is allowed.

The build order buys what each round needs first: the cheapest step towards your end crosspaths that answers the next threat, in time for the round it first appears. Everything else is bought cheapest-first, but only while every upcoming need can still be paid for. Banana Farms are bought early so they pay back. The order is then run through the Simulator, so the cash, the leaks and the fixes are the Simulator's own.

Coverage means a tower can hit a bloon type, not that it has enough damage, and support is assumed to be in range. Use the key rounds and the Simulator to check the hard rounds. Calculated from the site's data, not play-tested.
