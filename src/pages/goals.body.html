My goals

Pick the Paragon or tier 5 you want. Log your runs, spend the XP like you do in the game, and see how many runs are left. Saved in this browser.

About this data

Unlock costs and Paragon XP come from the tower data. The unlock order is cheapest first and never skips a tier, the same as the XP calculator. XP per run is the round XP for the mode on your hardest map tier, with Monkey Education and Elite Military Training if you tick them, assuming only that tower is built. The game's end screen shows the real XP you earned: type that in for exact tracking.

Your progress is stored in this browser only (localStorage). Use the backup code to move it to another device. Clearing site data deletes it.
