XP calculator

Tap the upgrades you've unlocked, pick what you want next. It shows the XP left, the unlock order and the fastest farm.

About this data

Upgrade XP comes from the tower data. A few upgrades have unknown XP and count as 0; the page says when that affects you. The farm table assumes the tower is the only one you spend on, so it takes the whole run's XP. Run times are rough fast-forward estimates.
