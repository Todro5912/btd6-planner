# Glossary

## Notation and measures

| Term | Meaning |
|---|---|
| **x-y-z / crosspath** | Upgrades bought in the top, middle and bottom paths, e.g. 2-0-5. Only one path can go past tier 2. "Crosspath" also means the secondary path (max tier 2) |
| **T5 / tier 5** | The final upgrade on a path |
| **RBE** | Red Bloon Equivalent: total hits needed to pop a bloon and all its children |
| **RBS** | Red Bloon Seconds: how long a plain Red Bloon takes to walk a lane. The standard measure of track length |
| **LoS** | Line of sight. A LoS blocker is scenery that towers can't shoot through. The range circle shows blocked areas in red |
| **Med-eq** | Medium-equivalent: cash divided by a mode's price multiplier |
| **(calc)** | On this site: a number worked out from the data by arithmetic |

## Modes and challenges

| Term | Meaning |
|---|---|
| **CHIMPS** | No Continues, Hearts lost, Income, Monkey Knowledge, Powers or Selling. 1 life, R6–100, Hard prices |
| **ABR** | Alternate Bloons Rounds: the harder round set unlocked after Hard Standard |
| **BB / black border** | Every medal on a map, including black CHIMPS |
| **Red / black CHIMPS** | Red: any CHIMPS win. Black: one session, no exit, no Retry Last Round |
| **2TC / 3TC / 1TC** | Beat CHIMPS with only 2 (3, 1) towers. 2TC is also a hidden achievement that rewards a Summon Phoenix Insta |
| **2MP** | A CHIMPS win using a single tower or hero. The BTD6 Index keeps the lists |
| **LCC** | Least Cash CHIMPS: a CHIMPS win spending as little as possible |
| **FTTC** | Fewest Types of Towers CHIMPS (unverified) |
| **Freeplay** | Playing on past a difficulty's final round |
| **Sandbox** | Test mode: infinite cash and lives, no rewards |
| **Insta / Insta Monkey** | A pre-upgraded tower you place for free. Counts as a Power |
| **MK** | Monkey Knowledge, the permanent bonuses |
| **MM** | Monkey Money |
| **Index** | The BTD6 Index, a community records site for 2TC, 2MP, LCC and map data |

## Bloons

| Term | Meaning |
|---|---|
| **MOAB-class / blimp** | MOAB, BFB, ZOMG, DDT and BAD, plus bosses |
| **fMOAB / fDDT / fBAD** | Fortified versions |
| **Super Ceramic** | An R81+ Ceramic: 60 HP, one child per layer |
| **Decamo / de-lead / defortify** | Removing that property from a bloon |
| **Leak** | A bloon reaching the exit |

## Towers and upgrades

| Term | Meaning |
|---|---|
| **MIB** | Monkey Intelligence Bureau, Village x-3-x. Nearby towers pop every bloon type |
| **TSG / VTSG** | True Sun God, Super Monkey 5-x-x. The Vengeful True Sun God is made by sacrificing towers, including a Paragon |
| **GMN** | Grandmaster Ninja, Ninja 5-x-x |
| **BRF** | Banana Research Facility, Farm 4-x-x |
| **MWS** | Monkey Wall Street, Farm x-x-5 |
| **BMA** | Bloon Master Alchemist, Alchemist x-x-5. Sometimes written BMC, which usually means the separate game Bloons Monkey City |
| **BEZ / BADS** | Bloon Exclusion Zone (Dartling x-x-5) / Bloon Area Denial System (x-x-4) |
| **PMFC / SMFC** | Plasma Monkey Fan Club / Super Monkey Fan Club, Dart x-5-x / x-4-x |
| **POA / P&A** | Pop and Awe, Mortar x-5-x |
| **TBO / TBO2** | The Big One / The Biggest One, Mortar 4-x-x / 5-x-x |
| **LOTN** | Legend of the Night, Super Monkey x-x-5 |
| **SotF** | Spirit of the Forest, Druid x-5-x |
| **AAS** | Archmage, Wizard 5-x-x (unverified abbreviation) |
| **MPL** | Usually read as Pirate Lord, Buccaneer x-5-x (unverified abbreviation) |
| **Paragon** | A sixth tier made when all three tier 5s of one tower are on the map. Its Degree (1–100) depends on what it absorbs |
| **Degree** | A Paragon's power level, 1 to 100 |
| **Totem** | Paragon Power Totem, bought from Geraldo at level 20+ |

## Strategy

| Term | Meaning |
|---|---|
| **Farming** | Investing in income towers early to spend later. Also used for grinding tower XP |
| **Eco** | Economy: farms, banks and other income |
| **Wincon** | Win condition: the tower that carries the late game |
| **Carry** | The main damage tower at a given point |
| **Micro** | Active manual control: abilities, retargeting, moving towers |
| **Stall** | Slowing or pushing bloons back to buy time: glue, ice, MOAB Press, Bloon Crush |
| **Sell-reset / sell-rebuy** | Selling a tower to reset cooldowns or to place a discounted copy. Not allowed in CHIMPS |
| **Sacrifice** | Spending tower value into a Sun Temple, TSG or Paragon to make it stronger |
| **Opener** | The first towers of a game, usually 3 Darts or a hero |
| **Share (XP)** | The fraction of round XP a tower gets, set by cash invested |
